# OVX Full Version Roadmap

## Principle
Do not expand autonomy until the single-agent coding loop is reliable, measurable, and secure.

## Stage 1 — Strong local agent
Mature repository intelligence, multi-language support, richer framework adapters, larger eval suite, better patching, local task history.

## Stage 2 — Integrations
GitHub, GitLab, issue-to-task, PR review, CI integration, VS Code.

## Stage 3 — Remote execution
Remote isolated workers, snapshots, artifact storage, distributed queue, controlled network.

## Stage 4 — Team workspaces
Organization repositories, team permissions, shared history, reusable policies/skills, audit dashboards.

## Stage 5 — Model routing
Selection by task, privacy, cost, latency, context size, and reliability.

## Stage 6 — Multi-agent
Only after single-agent stability. Possible roles: investigator, implementer, reviewer, tester. All use the same tool/policy system.

## Stage 7 — Enterprise
SSO, RBAC, centralized audit, retention controls, policy administration, self-hosted deployment, compliance support, private model infrastructure.

## Quality gates
Every stage preserves task-success baseline, security baseline, recovery guarantees, auditability, and user control.
