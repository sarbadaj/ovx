# OVX setup guide

The current setup and usage instructions are in the root [README.md](README.md).

OVX now includes a managed local-service CLI and VS Code extension. Use `bin/ovx setup`, `bin/ovx setup-model`, `bin/ovx start`, and `bin/ovx install-extension`; the former multi-terminal setup is obsolete.
