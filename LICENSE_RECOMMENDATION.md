# OVX License Recommendation

Finalize a license before accepting external contributions.

## Recommended candidate
**Apache License 2.0**

Reasons to consider it:
- permissive;
- explicit patent grant;
- common for developer infrastructure;
- supports commercial use and modification.

## Before adopting
Ompirit Software should confirm:
- commercial model;
- contribution strategy;
- licensing for hosted/enterprise components;
- trademark policy;
- legal review if appropriate.

After the decision, replace this recommendation with the actual `LICENSE` text and update the README.
